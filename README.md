# POST SERVICE GO

Пример Rest API для создания, получения, изменения и удаления постов с прикрепленными файлами.

## swagger

Доступен по пути `/swagger/index.html`

## RUN

`make dc_run` - запуск докера с базой и миграциями  
`go run ./cmd/main.go`
